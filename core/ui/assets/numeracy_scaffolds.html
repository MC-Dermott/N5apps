Decimal column calculator

Line up the decimal points, then work through the sum column by column, right to left — carrying or borrowing a ten whenever you need to.

Always start with the column furthest to the right. When adding, write any carried ten in the small box above the next column yourself; when subtracting, watch the borrow row above each column.

Lattice multiplication

Fill in the digits around the grid, multiply cell by cell, then add along the diagonals — carrying into the next one whenever you need to.

Multiply along each row and column, splitting the answer across the diagonal — tens above the line, units below — then add down each diagonal strip.
